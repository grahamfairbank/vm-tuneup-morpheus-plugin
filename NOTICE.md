# NOTICE: sources, attributions, disclaimer and trademarks

## Unofficial project

vm-tuneup-morpheus-plugin is an **independent, unofficial community project**. It is **not** a product of Hewlett Packard Enterprise (HPE) or Morpheus Data, LLC. It is not developed, reviewed, endorsed, sponsored, certified or supported by HPE or Morpheus Data.

The software is provided "as is", without warranty of any kind (see [LICENSE](LICENSE)). Use it at your own risk. Do not contact HPE support about it.

The plugin is read-only, except for one opt-in action. It never changes a VM's hardware, a host or a cluster. For users granted separate permissions, it can run fixed, read-only commands through Morpheus (a no-op and one read-only script inside VMs, and two read-only `virsh` queries on HVM hosts), and it can fill in a VM's **empty** guest OS fields in Morpheus after the user confirms. It never asks for or stores credentials. What it reports (for example "If you fix it" steps) is information, not advice: plan and test every change yourself, take a backup first, and follow HPE's documentation and support guidance for your environment.

### Test data

The test fixtures in `src/test/resources/fixtures` follow the shape of Morpheus 9.0.1 and 9.1 API responses measured on the author's own lab, but every name, address, MAC address suffix, UUID and id in them is made up or replaced. The guest scan fixtures (`fixtures/guest`) are guest script output, from lab VMs or written by hand, with names replaced. The host CPU fixtures (`fixtures/hostcpu`) are `virsh` output: one captured on a lab host and scrubbed (UUID zeroed), the others crafted from it to cover other CPU generations and vendors. A test (`FixtureHygieneSpec`) fails if real-looking addresses, UUIDs or MAC addresses come back.

### Screenshots

The screenshots in `docs/images` show the plugin on the author's own Morpheus appliance. Every cluster, host, VM and appliance name, address and MAC address is replaced with a consistent example value (for example `cluster-a`, `hvm-host-01`, `app-legacy-01`, `192.0.2.x`); see [docs/images/SCREENSHOT-SPEC.md](docs/images/SCREENSHOT-SPEC.md). The Morpheus user interface they show belongs to HPE.

### What the plugin jar contains

Only this project's own compiled classes, five page templates, one script and one icon. The two guest scripts are text constants in the compiled classes. It contains no third-party code. The Morpheus plugin API, Groovy and other runtime libraries are supplied by the Morpheus appliance at run time.

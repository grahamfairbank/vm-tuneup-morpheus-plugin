# Screenshot specification

The screenshots in this folder come from a real Morpheus appliance running the plugin, supplied by the maintainer. Every sensitive value is **replaced with an example value** before the image is committed: either the lab objects carry the example names when the shot is taken, or the real value is painted over. The browser's address bar and tabs are cropped off.

`how-it-works.svg` is not a screenshot: it's generated by `tools/draw-how-it-works.py`.

## Example values

Use these and nothing else, so a reader sees the same name for the same thing in every image and every section of the docs:

| Thing | Example value |
|---|---|
| Morpheus appliance (manager) | `morpheus.example.com`; signed in as `admin` |
| HVM cluster | `cluster-a` |
| HVM hosts | `hvm-host-01`, `hvm-host-02`, `hvm-host-03` |
| Host CPU details | CPU and libvirt model names may stay; replace serial numbers, UUIDs and host names |
| The manager's own VM, if it appears | `manager-vm` |
| Role created by the script | `vm-tuneup-viewer` |
| IP addresses | `192.0.2.x` (the documentation range), for example `192.0.2.21` |
| MAC addresses | keep only the real vendor prefix, with a fake suffix: VMware `00:0c:29:00:00:01`, `00:0c:29:00:00:02`…; KVM `52:54:00:00:00:01`… |
| UUIDs | `00000000-0000-0000-0000-000000000000` or a made-up value |

## What to replace

| Category | Examples on these screens |
|---|---|
| People | Names, user names, email addresses; the initials beside the name in the top bar |
| Organization | Tenant, cloud, group, cluster, datastore and network names; company or domain names |
| Hosts and VMs | Host names and FQDNs, VM and instance names, IP addresses, the appliance URL |
| Hardware identity | MAC address suffixes, UUIDs, serial numbers, ids in links or URLs |
| Content | ISO names and volume paths, log lines, anything that names a real system or person |
| Guest check evidence | Computer and domain names, user names, NTP server names (use `ntp.example.com`), paths with real names |

**Paint the example value in place of the real one**: clear the text with the background color of that spot and write the example in a similar size and color. Block out only things that aren't text: photos, avatars, other companies' logos. Never blur: it can sometimes be reversed.

## Before you capture

- Where you can, give the lab objects the example names before capturing, so there's less to paint over.
- Use the **light theme**, browser zoom **100%**, and a window about **1920 px** wide.
- Save as **PNG**, with the file names above.
- Check every image at full size for leftover real values (tooltips, breadcrumbs, the tab row, links in the status bar) before committing.
